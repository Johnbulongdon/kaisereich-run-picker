    A COMMUNITY FIELD GUIDE

    One more campaign.

    Kaiserreich Run Picker helps you choose a country and political path for Hearts of Iron IV’s Kaiserreich mod, and remember the campaigns you have played.

    A small, curated beginning

    It is an incomplete sample, not a list of every route in those countries or the full mod. Each path links to the official source in the checklist. Some paths require unification or later elections; read the result notes before starting.

    How the draw works

    Fully random and Randomize both give every eligible country–path combination an equal chance. Spin country chooses equally among eligible countries; Spin path then chooses equally among that country’s eligible paths. Path → Country uses your selected ideology and draws equally among matching path records.

    Your progress, your browser

    Start run marks a path Played. Completed always requires your choice. No accounts, cookies, analytics or external database are used by this application. Progress stays in localStorage on this browser and website address, unless you export it. Private browsing or clearing site data may remove it.

    Independent and open source

    An unofficial community project, not affiliated with or endorsed by the Kaiserreich development team or Paradox Interactive. No game artwork is used. Application code is available under the repository’s MIT license; referenced Kaiserreich material remains with its respective owners.
