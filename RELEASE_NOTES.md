# Kaiserreich Run Picker 1.0.0

First stable release of the free, unofficial campaign picker and personal progress tracker.

[Use the app](https://johnbulongdon.github.io/kaisereich-run-picker/)

- Country → Ideology → Path selection, with manual choices or an animated wheel.
- Geographic country atlas, nation flags and ideology emblems.
- Confirmed ideology/path flag variants, with reference-flag fallbacks.
- Filters, searchable ideology-grouped checklist, campaign objectives and optional challenges.
- Browser-local progress with JSON export/import; no account required.
- 203 listed nations and 3,294 source-backed political options from the pinned Kaiserreich 1.6.4 snapshot.

## Scope

Political options can overlap within a campaign. This is not a complete or playtested catalogue of every possible route. Later nations and conditional outcomes are labelled. The map provides geographic reference, not mod political borders. Some flag variants remain unresolved. Data coverage will continue to improve independently of the application version.

Existing saved progress remains compatible. Export a backup before moving browsers or devices; localhost and the public website have separate saves.

## Verification

21 core tests and 81 browser checks cover selection, flags, filtering, progress, imports/exports, browser restart, error states and responsive layouts. The deployment workflow checks the public app before publishing this release.

Unofficial community project; not affiliated with the Kaiserreich team or Paradox Interactive. Game text and artwork retain upstream attribution.
